# Changelog

## Version 0.2

- Added an optional Tkinter/CustomTkinter desktop widget with a compact dark
  theme and summary card.
- Added background price refreshes, holdings management, snapshots, CSV export,
  allocation and portfolio-history charts, and clear unavailable-price states.
- Added persisted settings in `data/settings.json`.
- Preserved the v0.1 terminal launcher; use `python main.py --gui` for the
  widget.
